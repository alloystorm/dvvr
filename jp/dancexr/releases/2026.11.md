# DanceXR 2026.11 Release Notes

DanceXR 2026.11 は、Native を「見るだけのビューアー」から、キャラクターをポーズさせ、ペイントし、撮影できる場所へと変えます。どのアクターでもどのモーションの上からでも手足をつかんでポーズを付けたり、キャラクターの体に絵を描いたり、水を吹きかけたり、プレイヤーアバターとしてシーンに入り込んだりできます。Native と Unity アプリの両方で FBX と VRM モデルを読み込めるようになり、新しい Creator エディションではあらゆる解像度でのオフライン動画収録が加わります。アクターには右クリックのクイックメニューが付き、モデルの入れ替えはパーティクルのトランジションで行われ、パストレーサーとラスターの両方で映像がよりきれいになりました。

## 新機能

### ポーズツール

- **どのアクターでも、どのモーションの上でも**、手・足・体をドラッグしてポーズを付けられます。アクターはその時点のポーズでダンスから切り離され、ほかのアクターは再生を続けます。
- バランスソルバーがキャラクターを立たせ続けます。体重は両足の間で移り、持ち上げた足は宙に浮いたままになり、引き下げると脚が曲がったり座ったりします。
- **Resume** で、アクターを現在の時刻のモーションへ滑らかに戻せます。**Revert** で編集を元に戻せます。
- VR ではコントローラーで操作できます。ポーズツールはすべてのエディションで無料です。

### ボディペイントとスプレー（Pro）

- **ボディペイント**は、キャラクターの肌や衣服に直接描画します。Point、Stroke、Line、Polygon の描画モード、消しゴム、塗りつぶし、スタンプ画像をブラシとして使う機能があります。
- ブラシサイズ、スタンプの回転、描画モードは、マウスホイールまたは VR のスティックで調整します。ペイントした色はモデルと一緒に保存することもできます。
- **スプレーツール**はキャラクターに水を吹きかけます。発射速度、広がり、量のうち 2 つをコントロールに割り当てられ、**Shower** や **Fountain** のスポーンプリセットを保存できます。
- 水は**ペイントを洗い流し**、その色を体に沿って運びます。きれいな肌には染みが残り、水滴は色づきます。洗い流される速さは調整できます。
- グローバルな**ツールメニュー**で Select、Paint、Spray、Pose を切り替えます。各ツールは有効な間、ホイールと中ボタンを専有します。

### プレイヤーアバター（Pro）

- **プレイヤーアバター**として、シーンの中に立てます。デフォルトは男性の上半身ダミーで、zip パック内のものを含め、好きなモデルを選ぶこともできます。
- 立ち姿か座り姿かを選べ、座る場合は椅子が使えます。前傾、体重移動、腕や脚の位置を調整でき、アバターは歩くこともできます。
- デスクトップでは**三人称のオーバーザショルダー視点**を使えます。アイコンタクト、身長のスナップ、そしてカメラが頭に近いときに体を透過して見せるカメラフェードを備えます。
- 髪、衣服、ソフトボディ、PMX の物理が、アバターの体や VR の手と指に反応するようになりました。システム > 物理に、**Collide with Player** と **Collide with Other Actors** のスイッチがあります。
- アバターの腕にポーズツールを使って、手の位置を決められます。

### ストッキング（Pro）

- どのキャラクターにも**シアーなストッキング**を追加できます。肌の上にニットがシェーディングされ、体の動きに合わせて伸びるため、曲げた膝では薄くなり、肌が緩む部分では厚くなります。
- 裾の高さと角度を調整でき、ウェルト（縁取りの帯）とやわらかい／くっきりした縁も選べます。
- パストレーサーとラスターの両方で動作し、内蔵プリセットと自分のプリセットが使えます。

### FBX と VRM モデル

- **FBX と VRM のキャラクターを Native で読み込めます**（すべてのエディション）。ボーンは自動でマッピングされ、髪と衣装のパーツには物理が付き、エクスポーターのパスが間違っていてもテクスチャが見つかります。
- VRM モデルは、使用条件が分かるよう、アクターメニューにライセンス情報が表示されます。
- 複数のバリアントを含む zip のモデルは、選ぶ前に**プレビュー**が表示され、パック内の各モデルは最近使ったものやお気に入りとして個別に記録されます。

### クイックメニューとアクター操作

- **キャラクターを右クリック**するとクイックメニューが開きます。モーションの割り当て、バリアントや代替テクスチャの選択、ドレッシンググループの表示切り替え、カメラへのフレーミング、カメラの方を向く、位置や物理のリセット、アンロードができます。何もない場所を右クリックすると、ツール、再生、カメラのショートカットが出ます。
- モデルパックの**代替テクスチャセット**を、メニューまたはクイックメニューから切り替えられ、モデルと一緒に保存されます。
- **アクターの入れ替え**は、選択中のアクターを置き換え、その立ち位置を保ちます。
- キャラクターが**呼吸**するようになり、XPS モデルでは、まばたきやウインクなどの**まぶたの表情モーフ**が使えます。アイコンタクトとアイドルポーズも洗練されました。
- キャラクターは入れ替えや削除の際に**フレークとなって崩れ**、登場時にはフレークから形づくられます。残りのキャストは飛び跳ねる代わりに新しい位置へ**スライド**します。床のスピナーが、次のキャラクターが現れる場所を示します。

### 布と髪

- 布がより安定しました。接触はソルバー内部で解決され、衣装は**長距離アタッチメント**で伸びを抑えられ、**セルフコリジョン**をオンにできます。スカートは紐状に作ることもでき、ストランド間の結び付きも調整できます。
- **ラテラルリンク**がスカートのスリットの位置を検出するようになり、形を保つか自由に動かすかを調整できます。
- 髪のチェーンが正しい支点からぶら下がるようになり、長さが不均一な長いボーンのポニーテールも、倒れずに正しい位置に収まります。
- 体と髪や布との摩擦で、ストランドが体の中に押し込まれることはなくなりました。

### オフライン動画収録（Creator）

- **動画を収録**は、PC の描画速度に関係なく、任意の解像度とフレームレートでクリップをレンダリングし、音楽をミックスした MP4 または PNG シーケンスとして出力します。
- カメラのキーフレームのスクリプトやアクターの周りの周回でショットを制御できます。収録にはハンドルやカーソルなどの画面上の表示は含まれません。
- 収録メニューは Creator エディションで利用できます。

### ライティングとレンダリング

- ラスターモードに**プローブボリューム式グローバルイルミネーション**が加わり、レイトレースによる GI も改善され、ゴーストが減りました。
- パストレーサーがマテリアルの **Double sided** を尊重するようになり、影のカリングも効率化されました。
- 新しい**空のプリセット**（Morning、Noon、Sunset、Night）と、空と太陽の照明を分けたコントロールが加わりました。
- サブサーフェススキャタリング、肌の色調、ラスターのいくつかの輪郭線やライティングのアーティファクトを修正しました。
- フォグが環境光で光ることがなくなり、肌や鏡の中でも正しく描画されます。
- ルームメニューを整理しました。
- 初回起動時のグラフィックチェックを見直しました。

## 操作性の改善

- メニューのラベルはすべてタイトルケースに統一され、見直しと整理が行われました。
- UI が大きくなり、余白も広がり、テキスト入力にはオンスクリーンキーパッドが付きました。
- メッセージリストの読み込み項目で、Native が何を準備しているかが分かります。
- タッチスクリーンでのタッチ入力が動作します。
- フレームレートが一時的に落ちたあとに再生速度が跳ね上がることがなくなりました。
- VR のメニューとアバターのモーションが改善されました。

## ライセンス

- DanceXR Native のライセンスは **1 つのリリースごと**に有効になりました。新しいバージョンがリリースされると、買い切りのライセンスはサイレントチェックの後に自動で引き継がれます。Patreon と月額支援は、支援した月のリリースが対象です。
- 1 回のライセンス認証で複数のエディションをカバーできるようになり、Native は所有する最上位のティアを選びます。

## DanceXR HD、LW、RT

- **FBX キャラクターは Native と同じリーダーで読み込まれる**ようになり、従来のローダーを置き換えました。Daz や Unreal のエクスポートを含め、テクスチャ、マテリアル、モーフがより一貫して扱われます。
- **VRM キャラクター**をドロップするか zip から読み込めるようになり、アクターメニューにライセンスが表示されます。
- FBX と VRM モデルは**ボーンの自動マッピング**に対応し、手動設定なしで踊れます。
- 髪、スカート、アクセサリーのチェーンを、スペースなしで番号が付いたストランドや、ぶら下がるものにちなんだ名前のモデルを含め、より多くのモデルで検出します。
- 髪のチェーンが正しい支点からぶら下がり、各セグメントと一緒に回転するため、長いボーンのポニーテールが傾いたり、1 セグメント遅れたりしなくなりました。
- 体との摩擦で、ストランドが体の中に押し込まれることがなくなりました。
- 物理エディターで、ボックス形状がタブレットに誤って変換される問題を修正しました。

## このアップデートの概要

- どのアクターにも、どのモーションの上でも使えるポーズツール
- ボディペイント、スプレーツール、ペイントを洗い流す水
- 座りや三人称視点に対応したプレイヤーアバター
- 体に合わせて伸びるシアーなストッキング
- Native と Unity の FBX と VRM モデル対応
- アクターのクイックメニューと代替テクスチャセット
- キャラクターの登場・退場時のパーティクルトランジション
- 任意の解像度で収録できる Creator エディションの動画収録
- プローブボリューム GI、空のプリセット、レンダリングの修正
- 1 つのリリースごとに有効なライセンス

DanceXR 2026.11 では、パフォーマンスを見るだけでなく、ポーズを付け、ペイントし、その中に入り込み、収録できます。
