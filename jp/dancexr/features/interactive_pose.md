# インタラクティブポーズ

インタラクティブポーズは、複数のアクターを物理世界を共有する自己平衡型人形に変換します。Free Pose と同じように手動で各ポーズを設定してください——腕や脚、あるいは胴体や頭部を掴んでドラッグし、バランスソルバーが各キャラクターを足の上（またはロックされた座席の上に）立たせるように維持します。すべての体が同じシミュレーション内で生活しているため、キャラクターは互いに寄りかかり、押し合うことができ、別のキャラクターに対して保持されている手はそれらに掴み着くことができます。

## ポーズ設定 {#posing}

Free Pose と同一です：手/腕または足/脚をドラッグしてその肢を移動させます；足は dwell-to-pin（静止して空中でロックし、リリースすると落下）を使用します。胴体をドラッグして保持すると座ります。**Reset** はすべてのピンをドロップし、中立な立ち姿勢に戻します。

## ピン留め {#pinning}

ピン留めされた手や足は凍結されるのではなくスプリング制約によって保持されるため、シミュレーションの一部として引き続き機能します——別のキャラクターがそれに対して押し当てても、スプリングのようにピンに戻ります。**Pin Strength** はその強さを設定します：高い値はピンを強く保持し、低い値は肢が接触時に屈服して漂うことを許容します。

## 接触とアンカーリング {#contact--anchoring}

**Contact Reaction** は、別のキャラクターによって押し込まれる際にキャラクターがどのように反応するかを示すものです：2 つの体が沈み込むような接触は、代わりに体全体をずらすことで対応し、足は接地したままになります。それを上げてより堅牢な支えにし、0 に下げると体を自由に重ね合わせることができます。

手を別のキャラクターに対して保持して静止させると、**anchors** によって下の身体部分にアンカーリングされます——その後、パートナーを再ポーズする際にその部位に追従して移動します（肩にある手は肩に残り続けます）。**Anchor Reach** は手がロックする前に近づける必要がある距離です；0 に設定するとアンカーリングが無効になります。再度手をドラッグするか、**Reset** を使用してリリースします。アンカーリングは一方通行であり、保持されているキャラクターは接触自体を除いてそれからの影響を感じません。

## ラグドール {#ragdoll}

**Ragdoll** は共有物理体のマスタースイッチです：これをオフにすると、各キャラクターは依然としてポーズを設定しバランスを保ちますが、互いに通り抜けてしまいます。
**Drive Strength** は物理体が設定されたポーズにどの程度強く保持されるかを決定します（低い値ほど接触時に屈服します）；**Damping** はそれを安定させます。

**World Pose Pull** はその保持のより弱いバージョンです。関節は各骨を親相対的に回転のみ再現するため、接触によって横に叩き出された腕は長期間正しくない方向を指し続けます——肩以下のすべての骨は、動かない肩に対して依然として正しい相対位置を保ちます。これは各部品をポーズが要求した方向へと誘導します。変位した肢が元の位置に戻るまで上げて設定し、体が接触時に屈服しすぎないように引き下げて調整してください。

**Fine Tune** は各身体部分ごとに両方のドライブを 0（その部分が弛緩する）から 1（ドライブが許す限り強く保持される）までスケーリングします——胴体を堅く保ちながら腕をぶら下げたり、手だけを柔らかくしたりできます。

**Pose Recovery** は体が設定されたポーズにどの程度強く引き戻されるかを決定します。これは意図的に優しく設計されているため、キャラクターを動かしたり揺らしたりしても肢が曳き流されて振れるようになります——それが最終的な位置に留まるのではなく、その後どのように確実に落ち着くかを決めるだけです。これを 0 にすると、変位された体はそのまま変位したままになります。

**Surface Friction** は体が実際に触れている床や他の表面をどの程度強く掴むかを決定します。値を 1 にすると地面に触れる部分はそれに付着し、体の他の部分によってのみ引き離すことができます；値を下げることで滑って落ち着く部分を設定できます。

**Show Colliders** はキャラクターが実際に構成されている物理ボリューム——衝突するカプセル、スラブ、および球体——を描画し、**Show Joints** は各ペア間の接続と、許容される曲げ範囲を描画します。両方とも診断用です：これらを使用して、なぜ 2 つのキャラクターが特定の場所で接触するのか、またはなぜ肢が特定の位置で止まるのかを確認できます。

## 座り姿勢 {#sitting}

胴体（腰）をドラッグして静止させると、Free Pose と同じようにそれを座席としてロックします：キャラクターはそれの上に椅子のように休まり、両足が自由にぶら下がります。素早いドラッグ＆リリースまたは **Reset** を使用すると再び立ち上がります。座っているキャラクターは依然として共有シミュレーションの完全な一部であり、座席は釘ではなくスプリングであるため、別のキャラクターがそれに対して寄りかかり押し出してやめさせることができ、その後落ち着きます。**Seat Stiffness** と **Seat Damping** はその堅牢さと速度を設定します；柔らかい座席ほど接触時に屈服します。**Seat Pin Strength** は *物理* 体に対する対応する保持です：これを下げると座っているキャラクターはより遠くまで漂い、戻るのに時間がかかります；上げて設定するとほとんど移動しない座席になります。**Seat Radius**、**Seat Lean Gain**、および **Seat
Lean Max** は上半体のカウンターバランス傾きを制御します；これは、座った骨盤が直立している場合のようにバランスを追うために滑ることはできないためです。

## 反復運動 {#repeating-motion}

**Motion** はオプションの反復身体運動を追加します——臀部は **Motion Range** を往復し、**Motion Speed** で速度を設定します。**Motion Orientation** は移動する線の傾きを調整し、真っ直ぐな前後から真っ直ぐな上下まで変更できます。**Motion Origin** はその移動の中心をシフトさせ、運動がキャラクターが休んでいる位置の前または後ろに座ることを可能にします；**Motion Speed** を 0 に残すと、臀部は単にそのオフセットで保持され続けます。**Motion Phase** は各キャラクターに独自の開始点を付与するため、仲間が同期して移動することを防ぎます。
