# ストッキング

**ストッキング**は、DanceXR Native でキャラクターの肌の上にシアーなニットをかぶせます。衣装のメッシュではなく、肌自身のマテリアルに、ニットが張られているかのようなシェーディングを施すため、どのモデルでも、パストレーサーとラスターの両方のレンダラーで動作します。ニットは**肌が伸びる場所（曲げた膝など）では薄く**、**緩む場所では厚く**なり、体の動きに追従します。すべてのエディションで **Pro** 機能です。

**Actors > アクター > Stockings** でオンにします。

---

## 覆う範囲

- **Region** で届く範囲を選びます：脚、脚と腰、体、または体と腕。手は決して覆われません。
- **Height** はモデルの最も低い点からの裾の高さ、**Angle** は裾を左右に傾ける角度（負の値は外側に向かって上がる）、**Edge** は裾のぼかし（0 でくっきりした線）です。裾は、ポーズに関係なく脚の同じ場所に留まります。

## 見た目

**Colour** と **Smoothness**（生地の光沢）で、ニットの見た目を決めます。**Base Density** は、正面から伸ばさずに見たとき生地が肌をどれだけ隠すかで、低いほどシアー、1 で不透明です。**Taper** は上に向かって糸を増やし、太ももが伸びに対して色を保つようにします。**Fresnel Power** は、四肢のシルエットに向かって生地がどれだけ速く厚くなるかを決めます。**Live Update** は毎フレームポーズを測り直し、伸びや折れが体に追従するようにします。**Skin Only** は、その範囲にある衣服や靴に生地をかけないようにします。

### Welt and Edge

裾のすぐ内側にある、厚手のニットの帯です。ストッキングの上端の仕上げに当たります。

- **Welt Width** と **Welt Density**：帯そのものと、それが肌をどれだけ隠すか。
- **Rim Width** と **Rim Bump**：帯の縁で巻き上がったリムの盛り上がり。
- **Skin Width** と **Skin Bump**：裾のすぐ外側で、肌が押し込まれる様子。

## Signals

**Signals** サブメニューでは、ニットを薄くしたり厚くしたりする要因を選びます。

- **Relaxed Girth** と **Girth Strength**：生地の伸ばさない状態の周長。体がそれより太い場所では、生地が引き伸ばされて薄くなります。
- **Pose Stretch Strength** と **Squeeze Strength**：ポーズの伸びが生地をどれだけ薄くするか、圧縮がどれだけ厚くするか。
- **Crease Strength (Rest)** と **Crease Strength (Pose)**：膝の裏のように、安静時の体にある折れ目と、ポーズによって生じる折れ目での厚み。
- **Fold Tightness** と **Fold Smoothing**：どの曲率を全面的に数えるか、折れがどの程度広がるか。
- **Minimum Density** と **Maximum Density**：伸びても折れても、生地がこれ以上シアーにも不透明にもならない限界。

## プリセット

内蔵プリセットですぐに始められます。自分のプリセットは、行のオルトアクションから保存できます。設定はモデルと一緒に保存されます。
