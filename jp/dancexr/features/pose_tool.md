# ポーズツール

**ポーズツール**を使うと、DanceXR Native で任意のアクターの手・足・体をつかんで動かせます。**再生中のどのモーションの上でも**使えます。最初のドラッグで、そのアクターはその時点のポーズでダンスから切り離され、ほかのアクターは踊り続けます。バランスソルバーが、引っ張る動きに合わせてポーズ中のキャラクターを立たせ続け、体重を移し、座らせるため、ギズモを動かすのではなく、重さを持った体をポーズさせている感覚になります。

ポーズツールはすべてのエディションで無料です。XPS、PMX、FBX、VRM のモデルで動作し、VR でも使えます。

---

## ポーズを始める

1. バーのツールボタンから **Pointer Tool** メニューを開くか、何もない場所を右クリックして、**Pose** を選びます。**Next Tool** はボタンに割り当てて、ツールを順番に切り替えることもできます。
2. 任意のアクターの手足、胸や頭、または腰をドラッグします。

脚や腰に触れるまでは、アクターは切り離された時点のポーズを正確に保ちます。Pose メニューの見出しには、ポーズ中のアクター数が表示されます。

## 引く、固定する、座る

- **手**は、離した場所に留まります。
- **足**は、マーカーが緑になるまで静止すると空中でロックされます。緑のリングと十字が、固定されている箇所を示します。早く離すと脚は解放されて立ちます。
- **腰**：腰をドラッグして静止すると座ります。素早くドラッグして離すと立ち上がります。
- **リーチ**：マウスホイールで、つかんでいる手足の届く距離が変わります。**Alt+ホイール**で、つかんでいる手が前腕を軸に回転します。
- ポーズ中のアクターは、シーンが一時停止していても反応し続け、髪も動き続けます。

VR では、コントローラーで指してつかみ、スティックでリーチとチルトを操作します。

## Pose メニュー

| 項目 | 内容 |
|---|---|
| **Scene Paused** | すべてのアクターと音楽を静止させ、瞬間を選べるようにします。 |
| **Freeze All** | すべてのアクターを、その時点のポーズで切り離し、ポーズ編集できる状態にします。 |
| **Unpin and Stand** | 固定されたすべての足と腰の座りを解除し、脚を腰の真下にまっすぐ立たせます。 |
| **Undo Edits** | ポーズ中のすべてのアクターを、切り離した時点のポーズに戻します。保持は続きます。 |
| **Resume All** | ポーズ中のすべてのアクターを、現在の時刻のモーションへ滑らかに戻します。 |
| **Lower Avatar Hands** | [プレイヤーアバター](player_avatar)の手を解放します。 |

### Balance

**Balance** サブメニューでは、ポーズ中の体の挙動を調整します。

- **Shift Smoothing**：体重を片方の足からもう片方へ移すのにかかる時間。
- **Sway**：静止した立ち姿が固まって見えないようにする、わずかなゆらぎ。0 で完全に静止します。
- **Gravity**、**Leg Stiffness**、**Leg Damping**：体の下で脚が曲がり、落ち着く様子。
- **Stance Stiffness**：腰が支持基底面にどれだけ素早く追従するか。
- **Relax Rate**：解放された足が床に降りる速さ。

## 知っておくこと

- ポーズの保持はセッション中のみ有効で、シーンには保存されません。
- **Pose tool** を選択している間は、デスクトップでプレイヤーアバターの腕もドラッグできます。手は離した場所に留まり、アバターと一緒に歩いたり向きを変えたりします。
