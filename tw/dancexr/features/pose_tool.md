# 擺姿工具

**擺姿工具**讓你在 DanceXR Native 中抓住任意角色的手、腳或身體並移動它，**可在任何正在播放的動作之上使用**。第一次拖曳會讓該角色在目前姿勢處脫離舞蹈，其他角色繼續跳舞。平衡求解器會在你拖曳時讓被擺姿的角色保持站立、轉移重心或坐下，因此你擺的是一具有重量的身體，而不是移動一個操作控制點。

擺姿工具在所有版本中免費。它適用於 XPS、PMX、FBX 和 VRM 模型，也可在 VR 中使用。

---

## 開始擺姿

1. 從列上的工具按鈕開啟 **Pointer Tool** 選單，或右鍵點擊空白處，然後選擇 **Pose**。**Next Tool** 也是可綁定的按鈕，用來循環切換工具。
2. 拖曳任意角色的肢體、胸部或頭部，或臀部。

在你觸碰腿部或臀部之前，角色會精確保持脫離時的姿勢。Pose 選單的標題會顯示已擺姿的角色數量。

## 拖拉、固定與坐下

- **手**會停在你放開的位置。
- **腳**：保持靜止直到標記變綠，就會鎖定在空中；綠色圓環加十字表示被固定的部位。過早放開，腿就會被釋放並站立。
- **臀部**：拖曳臀部並保持靜止即可坐下。快速拖曳並放開則會站起。
- **伸展**：滑鼠滾輪改變所持肢體的伸展距離。**Alt+滾輪**會讓所持的手繞前臂滾轉。
- 被擺姿的角色即使在場景暫停時也會繼續回應，頭髮也會繼續擺動。

在 VR 中，用控制器指向並抓取，用搖桿控制伸展和傾斜。

## Pose 選單

| 項目 | 作用 |
|---|---|
| **Scene Paused** | 讓所有角色和音樂靜止，方便你挑選時刻。 |
| **Freeze All** | 讓所有角色在目前姿勢處脫離，隨時可以擺姿。 |
| **Unpin and Stand** | 釋放所有被固定的腳和臀部坐姿，讓雙腿筆直地站在臀部下方。 |
| **Undo Edits** | 讓所有被擺姿的角色回到脫離時的姿勢；它們仍保持受控狀態。 |
| **Resume All** | 在目前時間將所有被擺姿的角色平滑地融回其動作。 |
| **Lower Avatar Hands** | 釋放你的[玩家化身](player_avatar)的雙手。 |

### Balance

**Balance** 子選單用於調整擺姿時身體的表現：

- **Shift Smoothing**：身體把重心從一隻腳移到另一隻腳所需的時間。
- **Sway**：站姿時的輕微飄移，讓站立姿勢看起來不呆板。0 為完全靜止。
- **Gravity**、**Leg Stiffness** 和 **Leg Damping**：雙腿在身體下方如何彎曲與穩定。
- **Stance Stiffness**：臀部跟隨支撐面的快慢。
- **Relax Rate**：被釋放的腳落回地面的快慢。

## 須知

- 受控的姿勢僅在本次工作階段中保留，不會隨場景儲存。
- 選取**擺姿工具**時，在桌面端還可以拖曳玩家化身的手臂。手會停在你放開的位置，並隨化身行走和轉身。
