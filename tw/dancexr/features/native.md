# DanceXR Native

**DanceXR Native** 是一款獨立的 Windows 應用程式，可在支援光線追蹤的硬體上以完整的**路徑追蹤**算繪你的角色。它是專為基於 Unity 的 DanceXR 執行環境打造的配套應用，擁有自己的算繪器和設定，同時使用同一套整理好的內容庫。

Native 於 2026.8 進入公開預覽，並在支援 PMX 模型、多角色場景與 OpenXR VR 後，於 [2026.9](../releases/2026.9) **正式發布**。

下載：[github.com/alloystorm/dvvr/releases/tag/dxr-native](https://github.com/alloystorm/dvvr/releases/tag/dxr-native)

## 路徑追蹤帶來什麼

DanceXR 的 PC RT 版本是在傳統算繪器之上疊加光線追蹤效果（參見[光線追蹤效果](raytracing)）。Native 選擇了另一條路：整幅畫面都由路徑追蹤生成，光照是被模擬出來的，而不是近似出來的。

- **真實的光線彈射** —— 被燈照亮的牆面會把帶顏色的光投到附近的面孔上，無需探針，也無需烘焙。
- **柔和陰影**，帶有真實的半影，並隨著與遮擋物的距離而擴散。
- **真實的反射** —— 表面反射的是房間裡實際存在的東西，包括畫面外或攝影機背後的物體。
- **體積霧與光束** —— 霧層直接內建於路徑追蹤器中，因此光柱與丁達爾效應來自真實的光線傳播。

兩種算繪模式：

- **即時** —— 經過降噪與超解析度，達到可互動的影格率。擺姿、構圖與播放都在這個模式下進行。
- **參考** —— 用數秒時間累積取樣，得到乾淨無雜訊的畫面，適合輸出靜態圖。

## 執行需求

| | |
|---|---|
| 作業系統 | Windows |
| 顯示卡 | 支援光線追蹤（建議 NVIDIA RTX） |
| VR | 相容 OpenXR 的頭戴裝置與執行環境 |

如果你的顯示卡無法執行，應用會在啟動時說明原因，而不是無聲失敗。

## 支援的內容

這是下載前最需要了解的一點。

- **模型：PMX 與 XPS / XNALara**（`.pmx`、`.xps`、`.mesh`、`.ascii`），可以是單獨檔案或 ZIP 壓縮檔。
- **動作：VMD**（MikuMikuDance），包含鏡頭動作。

PMX 支援包括附加與繼承骨骼變形、IK、頂點／骨骼／材質／群組變形以及剛體物理。表情變形可以由 VMD 動作驅動，也可在 Actors 選單中調整。

### 版本與角色數量限制

免費版一次可算繪**一個角色**。拖入第二個模型會取代掉第一個，應用會在此時給出提示。已啟用的 Pro 安裝支援同時使用多個角色，每個角色都可擁有自己的模型設定、材質、物理、位置與動作。

## 使用方式

拖放是主要的操作入口——把模型、動作或 ZIP 拖到視窗上即可載入。介面分為 **Actors**、**Motion**、**Camera**、**Environment**、**Scene** 與 **System** 幾個標籤頁。可從 DanceXR Launcher 以桌面或 VR 模式啟動 Native。

### 擺姿與動作

- 帶音訊的 VMD 動作播放，透過共享時鐘保持同步。
- 沒有播放動作時的程序化待機動作，以及可以看向攝影機的眼神接觸。
- 腿部 IK 與雙腳貼地解算，讓腳穩穩落在地面上，而不是懸浮或下陷。
- 帶身體碰撞體的頭髮物理與形狀匹配軟體模擬，以及由 PMX 定義的剛體物理。

### 擺放角色

把滑鼠移到角色腳下會出現互動圓盤：拖曳可在地面上移動，滾輪可旋轉。這個圓盤是真正的自發光幾何體，它的光會實際照亮角色。

### 場景與房間

預設環境是一個程序化房間，帶有真實的窗戶開口、可調節的照明與體積霧。場景可以按名稱儲存和重新載入，並保留完整的角色陣容、位置、材質與動作指派。

### 材質

可逐材質調整粗糙度、金屬度、非等向性與次表面散射，並支援按名稱分組重新對應，讓你一次調整所有「hair」材質。

---

## 回報問題

Native 會為每次工作階段寫入紀錄檔，當機時還會保留傾印檔。**System** 標籤頁中提供 **Report Issue**、**Copy Diagnostics** 與 **Open Log**。回報問題時請附上紀錄檔。
