# DanceXR Native

**DanceXR Native** 是一款獨立的 Windows 應用程式，旨在以你的 PC 所能達到的最高畫質算繪角色：在支援光線追蹤的硬體上使用完整的**路徑追蹤**，其餘情況則使用**光柵算繪器**。它是專為基於 Unity 的 DanceXR 執行環境打造的配套應用，擁有自己的算繪器和設定，同時使用同一套整理好的內容庫。

Native 於 2026.8 進入公開預覽，並在支援 PMX 模型、多角色場景與 OpenXR VR 後，於 [2026.9](../releases/2026.9) 正式發布。**[2026.10](../releases/2026.10)** 新增了光柵算繪器、圖形設定自動偵測、布料、Wet Skin & Fluid、自動相機，以及無需重新啟動即可進入的 VR。

下載：[github.com/alloystorm/dvvr/releases/tag/dxr-native](https://github.com/alloystorm/dvvr/releases/tag/dxr-native)

## 一個應用，兩種算繪器

Native 在同一個應用程式中同時包含路徑追蹤器和光柵算繪器。首次啟動時，它會測量你的 GPU 並為你選擇算繪器和畫質級別，因此開始之前無需任何設定。可隨時在 **System > Graphics** 中使用 **Detect best settings** 重新偵測。

### 路徑追蹤帶來什麼

DanceXR 的 PC RT 版本是在傳統算繪器之上疊加光線追蹤效果（參見[光線追蹤效果](raytracing)）。Native 的路徑追蹤器選擇了另一條路：整幅畫面都由路徑追蹤生成，光照是被模擬出來的，而不是近似出來的。

- **真實的光線彈射** —— 被燈照亮的牆面會把帶顏色的光投到附近的面孔上，無需探針，也無需烘焙。
- **柔和陰影**，帶有真實的半影，並隨著與遮擋物的距離而擴散。
- **真實的反射** —— 表面反射的是房間裡實際存在的東西，包括畫面外或攝影機背後的物體。
- **體積霧與光束** —— 霧層直接內建於路徑追蹤器中，因此光柱與丁達爾效應來自真實的光線傳播。

兩種算繪模式：

- **即時** —— 經過降噪與超解析度，達到可互動的影格率。擺姿、構圖與播放都在這個模式下進行。
- **參考** —— 用數秒時間累積取樣，得到乾淨無雜訊的畫面，適合輸出靜態圖。

### 光柵算繪器

光柵算繪器適用於路徑追蹤過慢或完全無法使用的 PC，包括內建顯示卡。它共用相同的場景、角色、材質和物理，因此在一種算繪器中搭建的場景可以在另一種中開啟。

- 陰影、環境光遮蔽與環境光照，並帶有時間性反鋸齒。
- **DLSS 與 FSR 超解析度**，因此不支援 DLSS 的 GPU 也可以進行超解析。
- 在支援光線追蹤的 GPU 上，可選的**光線追蹤陰影、反射和全域光照**能以很小的開銷讓畫面更接近路徑追蹤器。
- 適用於 MMD 風格模型的**卡通與無光照著色**，詳見下文的材質部分。

在 **System > Graphics** 中選擇算繪器。在路徑追蹤器與光柵之間切換會重新啟動 Native，並還原你的場景。

### 光柵畫質檔位

在光柵模式下，**Raster quality tier** 決定整體級別：

| 檔位 | 使用的內容 |
|---|---|
| High | 環境光遮蔽，加上光線追蹤陰影、反射和全域光照 |
| Mid | 環境光遮蔽，加上光線追蹤陰影和反射 |
| Low | 環境光遮蔽與陰影貼圖 |
| Toon | 所有材質以卡通著色顯示，使用陰影貼圖 |
| Minimal | 所有材質以無光照方式顯示，適用於最弱的硬體 |

如果某個檔位要求的功能你的 GPU 無法實現，Native 會自動退回，並告訴你它更改了什麼。

## 執行需求

| | |
|---|---|
| 作業系統 | Windows |
| 顯示卡（光柵） | 支援 DirectX 12，包括內建顯示卡 |
| 顯示卡（路徑追蹤） | 支援光線追蹤的獨立顯示卡（建議 NVIDIA RTX） |
| VR | 相容 OpenXR 的頭戴裝置與執行環境 |

如果你的顯示卡無法執行路徑追蹤器，Native 會以光柵模式啟動，而不會拒絕啟動。

## 支援的內容

這是下載前最需要了解的一點。

- **模型：PMX 與 XPS / XNALara**（`.pmx`、`.xps`、`.mesh`、`.ascii`），可以是單獨檔案或 ZIP 壓縮檔。包含多個 PMX 模型的 ZIP 可讓你選擇要載入的模型。
- **動作：VMD**（MikuMikuDance），包含鏡頭動作。
- **影片**：內容庫 `videos` 資料夾中的影片，用於房間的影片牆。

PMX 支援包括附加與繼承骨骼變形、IK、頂點／骨骼／材質／群組變形以及剛體物理。表情變形可以由 VMD 動作驅動，也可在 Actors 選單中調整。

XPS 模型與 PMX 模型以相同的方式適配動作，因此雙腳會穩穩踩在地面。XPS **換裝群組**可開關可選的服裝部件，**骨骼對應**編輯器可修復骨骼未被自動識別的模型。

還沒有自己的模型？可從 **Actors > Load** 載入內建的 **Dummy** 來試用動作。

### 版本與角色數量限制

免費版一次可算繪**一個角色**。載入第二個模型會取代掉第一個，應用會在此時給出提示。已啟用的 Pro 安裝支援同時使用多個角色，每個角色都可擁有自己的模型設定、材質、物理、位置與動作。在 Pro 中，**Load mode** 開關用於選擇新模型是取代現有陣容還是加入其中。

Pro 還可解鎖下文介紹的 Wet Skin & Fluid。

## 使用方式

拖放是主要的操作入口——把模型、動作或 ZIP 拖到視窗上即可載入。介面分為 **Actors**、**Motion**、**Camera**、**Environment**、**Scene** 與 **System** 幾個標籤頁。滑桿帶有 -/+ 按鈕、滑鼠滾輪調整，以及用於輸入精確數值的數字鍵盤。

Native 會在多次啟動之間記住你的系統設定，並還原上次工作階段。如果該工作階段中的某些內容導致 Native 在啟動時當機，下次啟動會跳過它而不會再次當機。

### 擺姿與動作

- 帶音訊的 VMD 動作播放，透過共享時鐘保持同步。
- 播放模式：單曲、單曲循環、清單、清單循環和隨機播放。
- **隨機播放**會挑選下一支舞蹈或換入另一位演員，並根據你的觀看習慣學習。
- 逐動作的音樂偏移、靜止姿勢（包括 T 姿勢）以及 **Center pivot** 設定，後者用於修正由遊戲骨架轉換而來的動作。這些設定會套用於使用該動作的每個角色。
- 沒有播放動作時的程序化待機動作，以及可以看向攝影機的眼神接觸。帶有眼瞼骨骼的角色會眨眼，眼瞼也會隨視線移動。
- 腿部 IK 與雙腳貼地解算，讓腳穩穩落在地面上，而不是懸浮或下陷。

### 物理

- 頭髮、衣物和軟體物理被整理為**具名群組**，每組都有獨立的調整參數、開關和預設。設定群組時可直接在檢視區中拾取骨骼。
- 身體碰撞體，以及由 PMX 定義的剛體物理。
- 可從任意角色的 Physics 選單為其新增**布料服裝**。裙子會自動貼合腰部，與身體發生碰撞，並附帶可自行擴充的預設。

### Wet Skin & Fluid（Pro）

水滴落在角色身上，沿身體流下、匯合，並在身後留下濕潤的痕跡。水滴會回應角色自身的動作，因此快速揮動會把水帶向肢體末端，甚至將其甩出。它可同時作用於皮膚和衣物，並帶有濕髮效果，設定會隨每個模型儲存。

### 相機

- 自由飛行相機與環繞相機，以及 VMD 鏡頭動作。
- **自動相機**會按節拍將舞蹈切分為多個鏡頭，可調整節奏、運動、角度以及相機的遠近。
- 使用 Motion 選單中的 **Tap beat** 設定歌曲速度，或直接輸入 BPM 和節拍偏移。節拍資訊會按歌曲記憶。

### 擺放角色

把滑鼠移到角色腳下會出現互動圓盤：拖曳可在地面上移動，滾輪可旋轉。這個圓盤是真正的自發光幾何體，它的光會實際照亮角色。

### 場景與房間

預設環境是一個程序化房間，帶有真實的窗戶開口、可調節的照明與體積霧。它的正面牆可以是**練習鏡**，也可以是與音樂同步播放的**影片牆**（受光螢幕或 LED 牆）。場景可以按名稱儲存和重新載入，並保留完整的角色陣容、位置、材質與動作指派。

燈光可以重複排列為扇形、網格或一排，聚光燈還可以自動跟隨你的演員。

### 材質

可逐材質調整粗糙度、金屬度、非等向性與次表面散射，並支援按名稱分組重新對應，讓你一次調整所有「hair」材質。皮膚、頭髮和服裝群組還提供整組的次表面散射、表面細節和可見性控制。

在光柵模式下，每個材質都有一個著色模型——**Lit、Toon 或 Unlit**——可按材質、按群組或對整個角色設定。Toon 使用模型自帶的卡通漸層、球面貼圖和描邊。

### VR

- 可在 **System > VR** 中無需重新啟動即進入和退出 VR，也可以從 DanceXR Launcher 以 VR 模式啟動 Native。
- 桌面和 VR 各自儲存圖形設定，每個頭顯也儲存自己的設定。首次 VR 工作階段會在約十秒內自動調校。
- **注視點路徑追蹤**降低視野邊緣的開銷，並在支援眼動追蹤的頭顯上跟隨你的視線。
- 可選擇 Native 使用的 OpenXR 執行環境，而無需更改 PC 的預設設定。
- 按鍵可以在 VR 控制器、遊戲手把和鍵盤之間重新對應。

## 回報問題

Native 會為每次工作階段寫入紀錄檔，當機時還會保留傾印檔。**System** 標籤頁中提供 **Report Issue**、**Copy Diagnostics** 與 **Open Log**。回報問題時請附上紀錄檔。
