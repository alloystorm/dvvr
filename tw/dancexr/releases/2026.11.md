# DanceXR 2026.11 Release Notes

DanceXR 2026.11 讓 Native 從一個檢視器變成可以擺姿、繪製和拍攝角色的地方。你可以在任意動作之上抓住任意角色的肢體來擺姿，在角色身體上繪畫，向它噴水，或以玩家化身的身分走進場景。Native 與 Unity 應用現在都能載入 FBX 和 VRM 模型，全新的 Creator 版本還新增了最高 4K 的離線影片錄製。角色擁有了右鍵快捷選單，模型更換時會有粒子轉場效果，路徑追蹤與光柵兩種算繪器的畫面也都更乾淨。

## 新功能

### 擺姿工具

- 拖曳**任意角色**的手、腳或身體，即可在**任意動作之上**擺姿。角色會在目前姿勢處脫離舞蹈，其他角色繼續播放。
- 平衡求解器讓角色保持站穩：重心會在雙腳之間轉移，抬起的腳會懸在空中，向下拉動身體時腿會彎曲或坐下。
- **Resume** 會在目前時間將角色平滑地融回其動作。**Revert** 會復原你的編輯。
- 支援在 VR 中使用控制器操作。擺姿工具在所有版本中均免費。

### 身體彩繪與噴灑（Pro）

- **身體彩繪**可直接在角色的皮膚和衣物上繪畫。可選擇 Point、Stroke、Line 或 Polygon 繪製模式，支援擦除、填色，並可使用印章圖片作為筆刷。
- 筆刷大小、印章旋轉和繪製模式可透過滑鼠滾輪或 VR 搖桿調整。繪製的顏色也可以選擇隨模型一同儲存。
- **噴灑工具**會向角色噴水。可將發射速度、擴散或數量中的兩項綁定到控制上，並設定可儲存的 **Shower** 或 **Fountain** 生成預設。
- 水現在會**沖掉顏料**，並把顏色沿著身體帶下，在乾淨的皮膚上留下汙漬，並為水滴染色。沖刷的速度可調。
- 全域**工具選單**可在 Select、Paint、Spray 和 Pose 之間切換，工具啟用期間獨占滾輪和滑鼠中鍵。

### 玩家化身（Pro）

- 以**玩家化身**的身分站在場景中：預設是男性上半身人偶，也可以選擇任意模型，包括 zip 包中的模型。
- 可選擇站姿或坐姿，並配有椅子可坐。前傾、重心轉移、手臂和腿的位置均可調整，化身還可以行走。
- 桌面端提供**第三人稱過肩視角**，支援眼神接觸、身高吸附，以及相機靠近頭部時可透視身體的相機淡化。
- 頭髮、衣物、軟體和 PMX 物理現在會對化身的身體以及你的 VR 雙手和手指作出反應。系統 > 物理中提供 **Collide with Player** 和 **Collide with Other Actors** 開關。
- 使用擺姿工具拖曳化身的手臂，即可放置它的雙手。

### 絲襪（Pro）

- 可為任意角色新增**輕薄絲襪**。針織材質覆蓋在皮膚之上，並隨身體運動而拉伸，因此彎曲的膝蓋處會變薄，皮膚鬆弛的位置則更厚。
- 可控制襪口的高度和角度，並提供襪口邊帶，邊緣可選柔和或硬朗。
- 在路徑追蹤器和光柵算繪器中均可使用，內建預設，也可使用你自己的預設。

### FBX 與 VRM 模型

- **Native 可載入 FBX 和 VRM 角色**，所有版本均支援。骨骼自動對應，頭髮和服裝部件帶有物理，即使匯出器的路徑有誤也能找到貼圖。
- VRM 模型會在角色選單中顯示其授權條款，方便你了解模型的使用方式。
- 包含多個變體的 zip 模型現在會在選擇前顯示**預覽**，包內的每個模型也會作為獨立的最近使用和收藏項目被記錄。

### 快捷選單與角色控制

- **右鍵點擊角色**即可開啟快捷選單：指派動作、選擇變體或替代貼圖、顯示或隱藏著裝群組、將角色置於鏡頭中、面向相機、重設位置或物理，或解除載入。右鍵點擊空白處可使用工具、播放和相機快捷操作。
- 模型包中的**替代貼圖方案**可從選單或快捷選單切換，並隨模型一同儲存。
- **更換角色**現在會取代所選角色並保留其站位。
- 角色會**呼吸**，XPS 模型支援眨眼、眨單眼等**眼瞼表情變形**。眼神接觸和待機姿勢也得到了優化。
- 角色在被更換或移除時會**碎成薄片消散**，登場時則由薄片聚合而成。其餘角色會**滑動**到新的位置，而不是跳變。地面上的旋轉標記會顯示下一個角色將出現的位置。

### 布料與頭髮

- 布料表現更穩：接觸在求解器內部解決，服裝可使用**長距離附著**來防止拉伸，並可開啟**自碰撞**。裙子可建構為繩帶形式，繩股之間的連接也可調整。
- **橫向連結**現在能偵測裙子開衩的位置，並可調整為保持形狀或自由擺動。
- 頭髮鏈會從正確的支點垂下，長度不均的長骨骼上的馬尾也不再傾倒，而是正確就位。
- 身體與頭髮或布料之間的摩擦不再把髮絲推進身體裡。

### 離線影片錄製（Creator）

- **Record Scene**（位於場景選單）可按 720p 到 4K 或直式 1080 x 1920、24、30 或 60 fps 算繪片段，與你的 PC 即時繪製速度無關，並輸出混入音樂的 MP4。
- 可錄製整支舞蹈或指定時長，鏡頭可選目前視角、固定姿勢，或圍繞第一個角色環繞。錄製內容不包含螢幕上的控制點和游標。
- Record Scene 屬於 Creator 版本。

### 光照與算繪

- 光柵模式新增**探針體積全域光照**，光線追蹤 GI 也得到改進，鬼影減少。
- 路徑追蹤器現在會遵循材質的 **Double sided** 設定，陰影剔除也更高效。
- 新增**天空預設**（Morning、Noon、Sunset、Night），以及分開的天空與太陽光照控制。
- 修復了次表面散射、膚色以及若干光柵描邊和光照瑕疵。
- 霧不再因環境光而發光，並且在皮膚和鏡子中也能正確算繪。
- 房間選單已重新整理。
- 首次啟動時的圖形檢測已重新設計。

## 操作體驗改進

- 選單標籤統一採用標題大小寫，並經過審查與整理。
- 介面更大、間距更寬，文字輸入新增螢幕鍵盤。
- 訊息列表中的載入項目會顯示 Native 正在準備的內容。
- 觸控螢幕上的觸控輸入可正常使用。
- 影格率下降後，播放速度不再突然加快。
- 改進了 VR 選單和化身動作。

## 授權

- DanceXR Native 的授權現在**每個版本有效**。新版本發布時，買斷授權會在一次靜默檢查後自動沿用；Patreon 和月度贊助則對應其所贊助的版本。
- 一次授權啟用現在可以涵蓋多個版本，Native 會選取你擁有的最高等級。

## DanceXR HD、LW 與 RT

- **FBX 角色現在透過與 Native 相同的讀取器載入**，取代了舊的載入器。貼圖、材質和變形的處理更一致，包括 Daz 和 Unreal 匯出的模型。
- **VRM 角色**可拖入或從 zip 中載入，並在角色選單中顯示其授權。
- FBX 和 VRM 模型支援**自動骨骼對應**，無需手動設定即可跳舞。
- 頭髮、裙子和配件鏈在更多模型上得到偵測，包括股線編號不帶空格的模型，以及按懸掛之物命名的模型。
- 頭髮鏈從正確的支點垂下，並隨各自的段一同轉動，因此長骨骼上的馬尾不再傾倒或滯後一段。
- 與身體之間的摩擦不再把髮絲推進身體裡。
- 修復了物理編輯器中方塊形狀被錯誤轉換為平板的問題。

- Native 與 Unity 均支援 FBX 和 VRM 模型
- 角色快捷選單與替代貼圖方案
- 角色進出場時的粒子轉場
- Creator 版本支援最高 4K 的影片錄製
- 探針體積 GI、天空預設與算繪修復
- 每次僅對一個版本有效的授權

DanceXR 2026.11 讓你不只是觀看表演：你可以為它擺姿、為它繪畫、走進其中，並把它錄製下來。
