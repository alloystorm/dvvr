# DanceXR 2026.8 Release Notes

DanceXR 2026.8 的主題，是在你創作時安靜地退到一旁。擺姿手感全面提升——肢體緩緩到位而不再突然跳變，關節也不會朝錯誤的方向彎折；物理設定則會在你載入模型的那一刻自動完成，替你處理過去需要逐根骨骼選擇的工作。手部保持得更穩定，一批材質修復讓濕身效果和許多表面回到本該有的算繪結果。與此同時，一款全新的原生路徑追蹤應用進入公開預覽。

## 新功能

### 自動設定的物理

- 載入模型後，DanceXR 現在會自動偵測頭髮、裙子與軟體的骨骼鏈，並預先填好過去需要手動選擇的物理設定。
- 偵測在所有模型上遵循同一套規則，結果保持一致——當然你仍可以手動調整全部內容。

### 更貼手的擺姿

- 拖曳肢體現在帶有平滑處理，即使快速甩動滑鼠也不會突然跳變，而是緩緩到位。
- 手臂和腿不會再超出自然活動範圍。該限制現已內建於擺姿解算器本身，並新增了可選的手臂錐形限制。
- 腿部會連同腳尖一起進行到達計算，因此在伸展終點落腳更加自然。
- 移動與旋轉圓盤的位置更合理。

### 更好的抓握

- 手部保持得更穩定。在明確移開之前，握持會一直維持，不會在兩個鄰近對象之間來回閃爍。
- 手指可以同時環繞多個形狀，對象移動時握持也會隨之跟隨。
- 現在不僅能抓自己，還能抓住舞台道具和其他角色的身體。

### 材質與觀感

- 對材質系統的梳理修復了一批此前被錯誤分類的材質——玻璃、抖動、頭髮、地面以及路徑追蹤變體現在都能依預期算繪。
- 材質資源缺失時會明確回報，而不再靜默回退到錯誤的外觀。
- 濕身效果已恢復並進一步改進，包含全新的水體著色器、地面雨水修復以及更自然的雨滴分布。
- 新增光束著色器。

## 其他新內容

### DanceXR Native — 公開預覽

- 一款獨立的 Windows 應用程式，在 NVIDIA RTX 硬體上以完整路徑追蹤算繪角色——真實的光線彈射、柔和陰影與真實反射，而非即時近似。
- 透過拖放載入 XPS 模型與 VMD 動作，支援音訊播放、鏡頭運動、頭髮與軟體物理、雙腳貼地校正、程序化待機動作，以及帶體積霧和光束的程序化房間。
- 僅限桌面端（不支援 VR），需要配備支援光線追蹤 GPU 的 Windows 系統。免費預覽一次可算繪一個角色。這是早期公開預覽，會有粗糙之處，歡迎回饋。

## 改進

### 問題修復

- 修復了擺姿過程中骨盆偏移漂移的問題。
- 修復了姿勢視覺化尺寸不正確的問題。

## 本次更新一覽

- 載入模型時自動設定頭髮、裙子與軟體物理
- 平滑的肢體拖曳與自然的關節限制
- 連同腳尖一起到達的腿部，以及位置更合理的移動與旋轉圓盤
- 穩定保持、可跨多個形狀、並能觸及道具與其他角色的抓握
- 恢復的濕身效果、全新水體與光束著色器，以及材質修復
- 路徑追蹤檢視器 DanceXR Native 進入公開預覽

這個版本關注的，是那些你本不該費心去想的部分：會自我設定的物理、放到哪裡就留在哪裡的姿勢，以及依照製作意圖呈現的材質。
