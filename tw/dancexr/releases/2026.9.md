# DanceXR 2026.9 Release Notes

DanceXR 2026.9 是整個 DanceXR 家族向前邁出的重要一步。DanceXR Native 結束公開預覽正式發布，帶來 PMX 支援、多角色場景以及桌面與 VR 雙模式。全新的 DanceXR Launcher 將所有 Windows 執行環境和配套應用匯聚於一處。在 Unity 應用中，互動擺姿讓多角色之間的物理接觸與互動擺姿成為可能，同時布娃娃系統、程序化行走、PMX 相容性與實驗性流體也迎來了大幅升級。

## 新功能

### DanceXR Native 正式發布

- **DanceXR Native 已結束公開預覽。** 這款獨立的路徑追蹤應用程式現在已可在支援光線追蹤的 Windows PC 上勝任日常使用。
- Native 現在不僅支援 XPS/XNALara 模型，還可以載入 **PMX 模型**。PMX 支援包括 VMD 動畫、附加與繼承骨骼變形、IK、變形（Morph）以及剛體物理。
- 現已支援多角色場景。在同一個完全路徑追蹤的環境中同時載入、排列、製作動畫並儲存多個角色。免費版依然限制為一個角色；已啟用的 Pro 安裝可解鎖多角色。
- Native 現在可以以桌面或 **OpenXR VR** 模式啟動，啟動器會在啟動前檢查所需的硬體和執行環境。
- 儲存的場景會保留完整的角色陣容、位置、材質以及指派的動作，使 Native 從單一模型檢視器演變為完整的工作流程場景建構工具。

### 一個啟動器管理所有 DanceXR 應用

- 全新的 **DanceXR Launcher** 會尋找已安裝的 HD、LW、RT 與 Native 執行環境，並在單一視窗中為每個執行環境提供清晰的啟動入口。
- 如果未安裝 HD 或 Native，啟動器可以直接下載並安裝其免費版，方便在新電腦上輕鬆上手。
- 啟動器會自動檢查 **DanceXR Discovery** 和 **DanceXR Operator** 的已安裝版本，並在需要時提供安裝、更新或修復操作。
- Native 配備獨立的桌面與 VR 啟動按鈕，同時相容性檢查會在啟動前檢測是否缺少 DXR 或 OpenXR 支援，並在可能時提供合適的備用方案。
- 下載內容會在取代現有配套應用之前進行驗證並放入暫存區，因此更新中斷不會損壞正常運作的現有版本。

### 適用於多角色場景的互動擺姿

- **Interactive Pose 現已在 Pro 版中提供。** 將多個角色置於該模式下，即可將他們作為具有自平衡能力的物理人偶進行擺姿，角色之間可以相互推擠並產生反應。
- 角色會透過雙腳支撐並在接觸時轉移重心，而不是直接穿模或倒下。
- 拖曳的手部可以在另一個角色移動時保持固定在該角色上，讓相連的多角色姿勢編排變得更加容易。
- 接觸、固定強度、姿勢恢復、表面摩擦、身體驅動以及動作控制均可調整，可實現從嚴格受控的姿勢到更自然的物理反應等各種效果。
- 坐姿獲得了專門的支援，允許臀部和軀幹對座椅做出反應，同時角色依然保持設定的姿勢。

### 更好的布娃娃與身體接觸

- 布娃娃碰撞體現在更加貼合角色身形，頭部、腰部、軀幹、臀部、四肢等身體區域的形狀均得到改進。
- 新增的單部位形狀與微調控制，讓碰撞覆蓋範圍能夠適應特殊體型的角色比例。
- 布娃娃能更可靠地恢復到原有姿勢，接觸地面後不再黏滯在地板上，並且在移除角色或動作時能夠正確清理。
- Interactive Pose 與獨立的布娃娃系統現在可以協調控制權，防止兩套物理骨架爭奪同一個角色。
- 在微調設定時可以開啟碰撞體與關節的視覺化顯示。

### 更自然的程序化移動

- 走秀動作（Catwalk）經過大幅改良，可調整行走速度、步伐高度與時序、抬腳形態、膝蓋彎曲、腳尖離地、腳跟展現、軀幹傾斜以及頭部跟隨。
- 行走速度現在能更好地協調步頻與步幅之間的關係。
- 角色瞄準和移動更快，身體擺動、運動幅度與過渡時序均得到改善。
- 坐姿和空中姿勢的表現更加可預測，包括對雙腳何時應保持固定的判斷更加合理。

### 提升 PMX 模型相容性

- PMX 附加/繼承變換、變形順序以及物理前/後骨骼評估現在更忠實地遵循模型製作時的元資料。
- 現已支援受約束的 PMX 模型 IK 鏈，改善了除 DanceXR 標準腿部綁定之外依賴自帶 IK 的模型表現。
- PMX 阻尼、每剛體摩擦力、各軸關節彈簧以及自由軸限制現在能更真實地對應到 XPBD 解算器中。
- 在 XPBD 處於活動狀態時隱藏僅適用於 PhysX 的控制項，減少了在當前物理引擎下不起作用的設定項。

### 實驗性流體表面算繪

- HD 版本新增選用的 **Ray March Surface** 算繪器，可將流體粒子轉化為平滑且具有折射效果的表面。該功能明確處於實驗階段，預設處於停用狀態，需在流體設定中手動啟用。
- 水和牛奶預設提供了快速的起始設定，並提供對色調、不透明度、環境光、高光反應、菲涅耳邊緣、折射、表面半徑以及算繪細節的控制。
- 全新的脈衝發射可以建立重複的爆發噴射，同時擴充了吸引力、內聚力、黏度、黏附性、摩擦力、粒子大小以及核心範圍的控制。
- 改進了流體與地面、網格以及 SDF 的碰撞行為，包括對摩擦力、碰撞間隙、清理、重新建立以及算繪資源流失的修復。

## 操作體驗改進

- 新增算繪縮放設定，用於平衡畫質與 GPU 效能。
- 材質群組現在開放了完整的材質控制選項，並提供可靠的 **全部隱藏 (Hide All)** 和 **全部重設 (Reset All)** 操作。
- 可以為向上移動指派備用輸入。
- 網格碰撞體視覺化能正確更新，不再殘留無效物件。
- 大量物理修復改善了地面接觸、摩擦力、碰撞一致性，以及布料、粒子、流體和布娃娃系統的穩定性。

## 本次更新一覽

- DanceXR Native 結束預覽正式發布，支援 PMX、多角色以及 VR
- 用於啟動執行環境與安裝免費版的新啟動器
- Discovery 與 Operator 的自動版本檢查與託管更新
- Pro 版中支援物理多角色姿勢編排的 Interactive Pose
- 更加貼合身形且可調整的布娃娃碰撞體
- 坐姿專屬支援與更可靠的姿勢恢復
- 更自然且支援深度調整的程序化行走
- 更真實的 PMX IK、骨骼變形、阻尼、摩擦力與關節彈簧
- 帶有水和牛奶預設的實驗性平滑流體表面
- 算繪縮放與改進的材質群組控制

DanceXR 2026.9 將整個產品家族凝聚在一起：正式發布的原生路徑追蹤器、讓每個 Windows 應用都更容易找到與維護的啟動器，以及在同一場景中擁有更具說服力的動作、接觸與物理存在感的角色。
