# DanceXR Native

**DanceXR Native** 是一款独立的 Windows 应用程序，在 NVIDIA RTX 硬件上以完整的**路径追踪**渲染你的角色。它并不是 DanceXR 的某个版本，而是一款专门打造的配套应用，拥有自己的安装程序、自己的设置和自己的内容文件夹。

目前处于**公开预览**阶段（2026.8），会有粗糙之处。

下载：[github.com/alloystorm/dvvr/releases/tag/dxr-native](https://github.com/alloystorm/dvvr/releases/tag/dxr-native)

---

## 路径追踪带来什么

DanceXR 的 PC RT 版本是在传统渲染器之上叠加光线追踪效果（参见[光线追踪效果](raytracing)）。Native 选择了另一条路：整幅画面都由路径追踪生成，光照是被模拟出来的，而不是近似出来的。

- **真实的光线弹射** —— 被灯照亮的墙面会把带颜色的光投到附近的面孔上，无需探针，也无需烘焙。
- **柔和阴影**，带有真实的半影，并随着与遮挡物的距离而扩散。
- **真实的反射** —— 表面反射的是房间里实际存在的东西，包括画面外或摄像机背后的物体。
- **体积雾与光束** —— 雾层直接内建于路径追踪器中，因此光柱与丁达尔效应来自真实的光线传播。

两种渲染模式：

- **实时** —— 经过降噪与超分，达到可交互的帧率。摆姿、构图与播放都在这个模式下进行。
- **参考** —— 用数秒时间累积采样，得到干净无噪点的画面，适合出静态图。

## 运行要求

| | |
|---|---|
| 操作系统 | Windows |
| 显卡 | 支持光线追踪（推荐 NVIDIA RTX） |
| VR | **不支持** —— 仅限桌面端 |

如果你的显卡无法运行，应用会在启动时说明原因，而不是无声失败。

## 支持的内容

这是下载前最需要了解的一点。

- **模型：XPS / XNALara**（`.xps`、`.mesh`、`.ascii`），可以是单独文件或 ZIP 压缩包。
- **动作：VMD**（MikuMikuDance），包含镜头动作。

**目前尚不支持 PMX 模型。** PMX 是 Native 接下来的重点篇章，它会一并带来变形、附加/旋转赋予以及 PMX 物理内容，但本次预览中没有。如果你的内容库全是 PMX，这个版本暂时还派不上多少用场。

由于 XPS 没有变形数据，表情变形目前同样不可用。

### 预览版限制

免费预览一次可渲染**一个角色**。拖入第二个模型会替换掉第一个，应用会在此时给出提示。

## 使用方式

拖放是主要的操作入口——把模型、动作或 ZIP 拖到窗口上即可加载。界面分为 **Actors**、**Motion**、**Camera**、**Environment**、**Scene** 与 **System** 几个标签页。

### 摆姿与动作

- 带音频的 VMD 动作播放，通过共享时钟保持同步。
- 没有播放动作时的程序化待机动作，以及可以看向摄像机的眼神接触。
- 腿部 IK 与双脚贴地解算，让脚稳稳落在地面上，而不是悬浮或下陷。
- 带身体碰撞体的头发物理与形状匹配软体模拟。

### 摆放角色

把鼠标移到角色脚下会出现交互圆盘：拖动可在地面上移动，滚轮可旋转。这个圆盘是真正的自发光几何体，它的光会实际照亮角色。

### 场景与房间

默认环境是一个程序化房间，带有真实的窗户开口、可调节的照明与体积雾。场景可以按名称保存和重新加载，并保留角色位置、材质与动作分配。

### 材质

可逐材质调整粗糙度、金属度、各向异性与次表面散射，并支持按名称分组重映射，让你一次性调整所有「hair」材质。

## 反馈问题

Native 会为每次会话写入日志，崩溃时还会保留转储文件。**System** 标签页中提供 **Report Issue**、**Copy Diagnostics** 与 **Open Log**。反馈问题时请附上日志。
