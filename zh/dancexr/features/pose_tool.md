# 摆姿工具

**摆姿工具**让你在 DanceXR Native 中抓住任意角色的手、脚或身体并移动它，**可在任何正在播放的动作之上使用**。第一次拖动会让该角色在当前姿势处脱离舞蹈，其他角色继续跳舞。平衡求解器会在你拖动时让被摆姿的角色保持站立、转移重心或坐下，因此你摆的是一具有重量的身体，而不是移动一个操纵柄。

摆姿工具在所有版本中免费。它适用于 XPS、PMX、FBX 和 VRM 模型，也可在 VR 中使用。

---

## 开始摆姿

1. 从栏上的工具按钮打开 **Pointer Tool** 菜单，或右键点击空白处，然后选择 **Pose**。**Next Tool** 也是可绑定的按钮，用来循环切换工具。
2. 拖动任意角色的肢体、胸部或头部，或臀部。

在你触碰腿部或臀部之前，角色会精确保持脱离时的姿势。Pose 菜单的标题会显示已摆姿的角色数量。

## 拖拽、固定与坐下

- **手**会停在你松开的位置。
- **脚**：保持静止直到标记变绿，就会锁定在空中；绿色圆环加十字表示被固定的部位。过早松开，腿就会被释放并站立。
- **臀部**：拖动臀部并保持静止即可坐下。快速拖动并松开则会站起。
- **伸展**：鼠标滚轮改变所持肢体的伸展距离。**Alt+滚轮**会让所持的手绕前臂滚转。
- 被摆姿的角色即使在场景暂停时也会继续响应，头发也会继续摆动。

在 VR 中，用手柄指向并抓取，用摇杆控制伸展和倾斜。

## Pose 菜单

| 项目 | 作用 |
|---|---|
| **Scene Paused** | 让所有角色和音乐静止，方便你挑选时刻。 |
| **Freeze All** | 让所有角色在当前姿势处脱离，随时可以摆姿。 |
| **Unpin and Stand** | 释放所有被固定的脚和臀部坐姿，让双腿笔直地站在臀部下方。 |
| **Undo Edits** | 让所有被摆姿的角色回到脱离时的姿势；它们仍保持被控状态。 |
| **Resume All** | 在当前时间将所有被摆姿的角色平滑地融回其动作。 |
| **Lower Avatar Hands** | 释放你的[玩家化身](player_avatar)的双手。 |

### Balance

**Balance** 子菜单用于调整摆姿时身体的表现：

- **Shift Smoothing**：身体把重心从一只脚移到另一只脚所需的时间。
- **Sway**：站姿时的轻微漂移，让站立姿势看起来不呆板。0 为完全静止。
- **Gravity**、**Leg Stiffness** 和 **Leg Damping**：双腿在身体下方如何弯曲与稳定。
- **Stance Stiffness**：臀部跟随支撑面的快慢。
- **Relax Rate**：被释放的脚落回地面的快慢。

## 须知

- 被控的姿势仅在本次会话中保留，不会随场景保存。
- 选中**摆姿工具**时，在桌面端还可以拖动玩家化身的手臂。手会停在你松开的位置，并随化身行走和转身。
