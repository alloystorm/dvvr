# DanceXR 2026.11 Release Notes

DanceXR 2026.11 让 Native 从一个查看器变成可以摆姿、绘制和拍摄角色的地方。你可以在任意动作之上抓住任意角色的肢体来摆姿，在角色身体上绘画，向它喷水，或以玩家化身的身份走进场景。Native 与 Unity 应用现在都能加载 FBX 和 VRM 模型，全新的 Creator 版本还新增了任意分辨率的离线视频录制。角色拥有了右键快捷菜单，模型更换时会有粒子过渡效果，路径追踪与光栅两种渲染器的画面也都更干净。

## 新功能

### 摆姿工具

- 拖动**任意角色**的手、脚或身体，即可在**任意动作之上**摆姿。角色会在当前姿势处脱离舞蹈，其他角色继续播放。
- 平衡求解器让角色保持站稳：重心会在双脚之间转移，抬起的脚会悬在空中，向下拉动身体时腿会弯曲或坐下。
- **Resume** 会在当前时间将角色平滑地融回其动作。**Revert** 会撤销你的编辑。
- 支持在 VR 中使用手柄操作。摆姿工具在所有版本中均免费。

### 身体彩绘与喷洒（Pro）

- **身体彩绘**可直接在角色的皮肤和衣物上绘画。可选择 Point、Stroke、Line 或 Polygon 绘制模式，支持擦除、填充，并可使用图章图片作为画笔。
- 画笔大小、图章旋转和绘制模式可通过鼠标滚轮或 VR 摇杆调整。绘制的颜色也可以选择随模型一同保存。
- **喷洒工具**会向角色喷水。可将发射速度、扩散或数量中的两项绑定到控制上，并设置可保存的 **Shower** 或 **Fountain** 生成预设。
- 水现在会**冲掉颜料**，并把颜色沿着身体带下，在干净的皮肤上留下污渍，并为水滴染色。冲刷的速度可调。
- 全局**工具菜单**可在 Select、Paint、Spray 和 Pose 之间切换，工具启用期间独占滚轮和鼠标中键。

### 玩家化身（Pro）

- 以**玩家化身**的身份站在场景中：默认是男性上半身人偶，也可以选择任意模型，包括 zip 包中的模型。
- 可选择站姿或坐姿，并配有椅子可坐。前倾、重心转移、手臂和腿的位置均可调整，化身还可以行走。
- 桌面端提供**第三人称过肩视角**，支持眼神接触、身高吸附，以及相机靠近头部时可透视身体的相机淡化。
- 头发、衣物、软体和 PMX 物理现在会对化身的身体以及你的 VR 双手和手指作出反应。系统 > 物理中提供 **Collide with Player** 和 **Collide with Other Actors** 开关。
- 使用摆姿工具拖动化身的手臂，即可放置它的双手。

### 丝袜（Pro）

- 可为任意角色添加**轻薄丝袜**。针织材质覆盖在皮肤之上，并随身体运动而拉伸，因此弯曲的膝盖处会变薄，皮肤松弛的位置则更厚。
- 可控制袜口的高度和角度，并提供袜口边带，边缘可选柔和或硬朗。
- 在路径追踪器和光栅渲染器中均可使用，内置预设，也可使用你自己的预设。

### FBX 与 VRM 模型

- **Native 可加载 FBX 和 VRM 角色**，所有版本均支持。骨骼自动映射，头发和服装部件带有物理，即使导出器的路径有误也能找到贴图。
- VRM 模型会在角色菜单中显示其许可条款，方便你了解模型的使用方式。
- 包含多个变体的 zip 模型现在会在选择前显示**预览**，包内的每个模型也会作为独立的最近使用和收藏项被记录。

### 快捷菜单与角色控制

- **右键点击角色**即可打开快捷菜单：分配动作、选择变体或替代贴图、显示或隐藏着装分组、将角色置于镜头中、面向相机、重置位置或物理，或卸载。右键点击空白处可使用工具、播放和相机快捷操作。
- 模型包中的**替代贴图方案**可从菜单或快捷菜单切换，并随模型一同保存。
- **更换角色**现在会替换所选角色并保留其站位。
- 角色会**呼吸**，XPS 模型支持眨眼、眨单眼等**眼睑表情形变**。眼神接触和待机姿势也得到了优化。
- 角色在被替换或移除时会**碎成薄片消散**，登场时则由薄片聚合而成。其余角色会**滑动**到新的位置，而不是跳变。地面上的旋转标记会显示下一个角色将出现的位置。

### 布料与头发

- 布料表现更稳：接触在求解器内部解决，服装可使用**长距离附着**来防止拉伸，并可开启**自碰撞**。裙子可构建为绳带形式，绳股之间的连接也可调整。
- **横向连接**现在能检测裙子开衩的位置，并可调整为保持形状或自由摆动。
- 头发链会从正确的支点垂下，长度不均的长骨骼上的马尾也不再倾倒，而是正确就位。
- 身体与头发或布料之间的摩擦不再把发丝推进身体里。

### 离线视频录制（Creator）

- **录制视频**可按任意分辨率和帧率渲染片段，与你的 PC 实时绘制速度无关，并输出混入音乐的 MP4 或 PNG 序列。
- 可通过相机关键帧脚本或围绕角色的环绕来驱动镜头，录制内容不包含屏幕上的控制柄和光标。
- 录制菜单在 Creator 版本中提供。

### 光照与渲染

- 光栅模式新增**探针体积全局光照**，光线追踪 GI 也得到改进，鬼影减少。
- 路径追踪器现在会遵循材质的 **Double sided** 设置，阴影剔除也更高效。
- 新增**天空预设**（Morning、Noon、Sunset、Night），以及分开的天空与太阳光照控制。
- 修复了次表面散射、肤色以及若干光栅描边和光照瑕疵。
- 雾不再因环境光而发光，并且在皮肤和镜子中也能正确渲染。
- 房间菜单已重新整理。
- 首次启动时的图形检测已重新设计。

## 操作体验改进

- 菜单标签统一采用标题大小写，并经过审查与整理。
- 界面更大、间距更宽，文本输入新增屏幕键盘。
- 消息列表中的加载条目会显示 Native 正在准备的内容。
- 触摸屏上的触控输入可正常使用。
- 帧率下降后，播放速度不再突然加快。
- 改进了 VR 菜单和化身动作。

## 许可

- DanceXR Native 的许可现在**每个版本有效**。新版本发布时，买断许可会在一次静默检查后自动沿用；Patreon 和月度赞助则对应其所赞助的版本。
- 一次许可激活现在可以覆盖多个版本，Native 会选取你拥有的最高等级。

## DanceXR HD、LW 与 RT

- **FBX 角色现在通过与 Native 相同的读取器加载**，取代了旧的加载器。贴图、材质和形变的处理更一致，包括 Daz 和 Unreal 导出的模型。
- **VRM 角色**可拖入或从 zip 中加载，并在角色菜单中显示其许可。
- FBX 和 VRM 模型支持**自动骨骼映射**，无需手动设置即可跳舞。
- 头发、裙子和配饰链在更多模型上得到检测，包括股线编号不带空格的模型，以及按悬挂之物命名的模型。
- 头发链从正确的支点垂下，并随各自的段一同转动，因此长骨骼上的马尾不再倾倒或滞后一段。
- 与身体之间的摩擦不再把发丝推进身体里。
- 修复了物理编辑器中方块形状被错误转换为平板的问题。

## 本次更新一览

- 适用于任意角色、任意动作的摆姿工具
- 身体彩绘、喷洒工具，以及能冲掉颜料的水
- 支持坐姿和第三人称视角的玩家化身
- 随身体拉伸的轻薄丝袜
- Native 与 Unity 均支持 FBX 和 VRM 模型
- 角色快捷菜单与替代贴图方案
- 角色出入场时的粒子过渡
- Creator 版本可按任意分辨率录制视频
- 探针体积 GI、天空预设与渲染修复
- 每次仅对一个版本有效的许可

DanceXR 2026.11 让你不只是观看表演：你可以为它摆姿、为它绘画、走进其中，并把它录制下来。
