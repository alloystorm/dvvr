# DanceXR 2026.8 Release Notes

DanceXR 2026.8 的主题，是在你创作时安静地退到一旁。摆姿手感全面提升——肢体缓缓到位而不再突然跳变，关节也不会朝错误的方向弯折；物理配置则会在你加载模型的那一刻自动完成，替你处理过去需要逐根骨骼选择的工作。手部保持得更稳定，一批材质修复让湿身效果和许多表面回到本该有的渲染结果。与此同时，一款全新的原生路径追踪应用进入公开预览。

## 新功能

### 自动配置的物理

- 加载模型后，DanceXR 现在会自动检测头发、裙子与软体的骨骼链，并预先填好过去需要手动选择的物理设置。
- 检测在所有模型上遵循同一套规则，结果保持一致——当然你仍可以手动调整全部内容。

### 更贴手的摆姿

- 拖动肢体现在带有平滑处理，即使快速甩动鼠标也不会突然跳变，而是缓缓到位。
- 手臂和腿不会再超出自然活动范围。该限制现已内建于摆姿解算器本身，并新增了可选的手臂锥形限制。
- 腿部会连同脚尖一起进行到达计算，因此在伸展终点落脚更加自然。
- 移动与旋转圆盘的位置更合理。

### 更好的抓握

- 手部保持得更稳定。在明确移开之前，握持会一直保持，不会在两个邻近对象之间来回闪烁。
- 手指可以同时环绕多个形状，对象移动时握持也会随之跟随。
- 现在不仅能抓自己，还能抓住舞台道具和其他角色的身体。

### 材质与观感

- 对材质系统的梳理修复了一批此前被错误分类的材质——玻璃、抖动、头发、地面以及路径追踪变体现在都能按预期渲染。
- 材质资源缺失时会明确报告，而不再静默回退到错误的外观。
- 湿身效果已恢复并进一步改进，包含全新的水体着色器、地面雨水修复以及更自然的雨滴分布。
- 新增光束着色器。

## 其他新内容

### DanceXR Native — 公开预览

- 一款独立的 Windows 应用程序，在 NVIDIA RTX 硬件上以完整路径追踪渲染角色——真实的光线弹射、柔和阴影与真实反射，而非实时近似。
- 通过拖放加载 XPS 模型与 VMD 动作，支持音频播放、镜头运动、头发与软体物理、双脚贴地校正、程序化待机动作，以及带体积雾和光束的程序化房间。
- 仅限桌面端（不支持 VR），需要配备支持光线追踪 GPU 的 Windows 系统。免费预览一次可渲染一个角色。这是早期公开预览，会有粗糙之处，欢迎反馈。

## 改进

### 问题修复

- 修复了摆姿过程中骨盆偏移漂移的问题。
- 修复了姿势可视化尺寸不正确的问题。

## 本次更新一览

- 加载模型时自动配置头发、裙子与软体物理
- 平滑的肢体拖动与自然的关节限制
- 连同脚尖一起到达的腿部，以及位置更合理的移动与旋转圆盘
- 稳定保持、可跨多个形状、并能触及道具与其他角色的抓握
- 恢复的湿身效果、全新水体与光束着色器，以及材质修复
- 路径追踪查看器 DanceXR Native 进入公开预览

这个版本关注的，是那些你本不该费心去想的部分：会自我配置的物理、放到哪里就留在哪里的姿势，以及按照制作意图呈现的材质。
