# DanceXR 2026.9 Release Notes

DanceXR 2026.9 是整个 DanceXR 家族向前迈出的重要一步。DanceXR Native 结束公开预览正式发布，带来 PMX 支持、多角色场景以及桌面与 VR 双模式。全新的 DanceXR Launcher 将所有 Windows 运行时和配套应用汇聚于一处。在 Unity 应用中，交互摆姿让多角色之间的物理接触与互动摆姿成为可能，同时布娃娃系统、程序化行走、PMX 兼容性与实验性流体也迎来了大幅升级。

## 新功能

### DanceXR Native 正式发布

- **DanceXR Native 已结束公开预览。** 这款独立的路径追踪应用程序现在已可在支持光线追踪的 Windows PC 上胜任日常使用。
- Native 现在不仅支持 XPS/XNALara 模型，还可以加载 **PMX 模型**。PMX 支持包括 VMD 动画、追加与继承骨骼变形、IK、变形（Morph）以及刚体物理。
- 现已支持多角色场景。在同一个完全路径追踪的环境中同时加载、排列、制作动画并保存多个角色。免费版依然限制为一个角色；已激活的 Pro 安装可解锁多角色。
- Native 现在可以以桌面或 **OpenXR VR** 模式启动，启动器会在启动前检查所需的硬件和运行时环境。
- 保存的场景会保留完整的角色阵容、位置、材质以及分配的动作，使 Native 从单一模型查看器演变为完整的工作流场景构建工具。

### 一个启动器管理所有 DanceXR 应用

- 全新的 **DanceXR Launcher** 会查找已安装的 HD、LW、RT 与 Native 运行时，并在单个窗口中为每个运行时提供清晰的启动入口。
- 如果未安装 HD 或 Native，启动器可以直接下载并安装其免费版，方便在新电脑上轻松上手。
- 启动器会自动检查 **DanceXR Discovery** 和 **DanceXR Operator** 的已安装版本，并在需要时提供安装、更新或修复操作。
- Native 配备独立的桌面与 VR 启动按钮，同时兼容性检查会在启动前检测是否缺少 DXR 或 OpenXR 支持，并在可能时提供合适的回退方案。
- 下载内容会在替换现有配套应用之前进行验证并放入暂存区，因此更新中断不会损坏正常运行的现有版本。

### 面向多角色场景的交互摆姿

- **Interactive Pose 现已在 Pro 版中提供。** 将多个角色置于该模式下，即可将他们作为具有自平衡能力的物理人偶进行摆姿，角色之间可以相互推挤并产生反应。
- 角色会通过双脚支撑并在接触时转移重心，而不是直接穿模或倒下。
- 拖拽的手部可以在另一个角色移动时保持固定在该角色上，让相连的多角色姿势编排变得更加容易。
- 接触、固定强度、姿势恢复、表面摩擦、身体驱动以及动作控制均可调节，可实现从严格受控的姿势到更自然的物理反应等各种效果。
- 坐姿获得了专门的支持，允许臀部和躯干对座椅做出反应，同时角色依然保持设定的姿势。

### 更好的布娃娃与身体接触

- 布娃娃碰撞体现在更加贴合角色身形，头部、腰部、躯干、臀部、四肢等身体区域的形状均得到改进。
- 新增的单部位形状与微调控制，让碰撞覆盖范围能够适应特殊体型的角色比例。
- 布娃娃能更可靠地恢复到原有姿势，接触地面后不再粘滞在地板上，并且在移除角色或动作时能够正确清理。
- Interactive Pose 与独立的布娃娃系统现在可以协调控制权，防止两套物理骨骼争夺同一个角色。
- 在微调设置时可以开启碰撞体与关节的可视化显示。

### 更自然的程序化移动

- 走秀动作（Catwalk）经过大幅改良，可调节行走速度、步伐高度与时序、抬脚形态、膝盖弯曲、脚尖离地、脚跟展现、躯干倾斜以及头部跟随。
- 行走速度现在能更好地协调步频与步幅之间的关系。
- 角色瞄准和移动更快，身体摆动、运动幅度与过渡时序均得到改善。
- 坐姿和空中姿势的表现更加可预测，包括对双脚何时应保持固定的判断更加合理。

### 提升 PMX 模型兼容性

- PMX 追加/继承变换、变形顺序以及物理前/后骨骼评估现在更忠实地遵循模型制作时的元数据。
- 现已支持受约束的 PMX 模型 IK 链，改善了除 DanceXR 标准腿部绑定之外依赖自带 IK 的模型表现。
- PMX 阻尼、每刚体摩擦力、各轴关节弹簧以及自由轴限制现在能更真实地映射到 XPBD 解算器中。
- 在 XPBD 处于活动状态时隐藏仅适用于 PhysX 的控件，减少了在当前物理引擎下不起作用的设置项。

### 实验性流体表面渲染

- HD 版本新增可选的 **Ray March Surface** 渲染器，可将流体粒子转化为平滑且具有折射效果的表面。该功能明确处于实验阶段，默认处于禁用状态，需在流体设置中手动启用。
- 水和牛奶预设提供了快捷的起始配置，并提供对色调、不透明度、环境光、高光反应、菲涅尔边缘、折射、表面半径以及渲染细节的控制。
- 全新的脉冲发射可以创建重复的爆发喷射，同时扩展了吸引力、内聚力、粘度、粘附性、摩擦力、粒子大小以及核心范围的控制。
- 改进了流体与地面、网格以及 SDF 的碰撞行为，包括对摩擦力、碰撞间隙、清理、重新创建以及渲染资源泄漏的修复。

## 操作体验改进

- 新增渲染缩放设置，用于平衡画质与 GPU 性能。
- 材质组现在开放了完整的材质控制选项，并提供可靠的 **全部隐藏 (Hide All)** 和 **全部重置 (Reset All)** 操作。
- 可以为向上移动分配备用输入。
- 网格碰撞体可视化能正确更新，不再残留失效对象。
- 大量物理修复改善了地面接触、摩擦力、碰撞一致性，以及布料、粒子、流体和布娃娃系统的稳定性。

## 本次更新一览

- DanceXR Native 结束预览正式发布，支持 PMX、多角色以及 VR
- 用于启动运行时与安装免费版的新启动器
- Discovery 与 Operator 的自动版本检查与托管更新
- Pro 版中支持物理多角色姿势编排的 Interactive Pose
- 更加贴合身形且可调节的布娃娃碰撞体
- 坐姿专属支持与更可靠的姿势恢复
- 更自然且支持深度调节的程序化行走
- 更真实的 PMX IK、骨骼变形、阻尼、摩擦力与关节弹簧
- 带有水和牛奶预设的实验性平滑流体表面
- 渲染缩放与改进的材质组控制

DanceXR 2026.9 将整个产品家族凝聚在一起：正式发布的原生路径追踪器、让每个 Windows 应用都更容易找到与维护的启动器，以及在同一场景中拥有更具说服力的动作、接触与物理存在感的角色。
