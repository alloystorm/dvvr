# DanceXR 2026.8 Release Notes

DanceXR 2026.8의 주제는 작업하는 동안 조용히 물러나 있는 것입니다. 포즈 작업 감각이 전반적으로 좋아져 팔다리가 튀지 않고 부드럽게 자리를 잡고, 관절은 이상한 방향으로 꺾이지 않습니다. 물리 설정은 모델을 불러오는 순간 알아서 잡히며, 예전에는 본을 하나씩 골라야 했던 작업을 대신해 줍니다. 손은 더 안정적으로 붙잡고, 여러 머티리얼 수정으로 젖은 표현을 비롯한 많은 표면이 본래 의도대로 렌더링됩니다. 여기에 더해, 완전히 새로운 네이티브 패스 트레이싱 앱이 공개 프리뷰를 시작합니다.

## 새로운 기능

### 알아서 잡히는 물리 설정

- 모델을 불러오면 DanceXR이 머리카락, 치마, 소프트바디 본 체인을 자동으로 감지해, 이전에는 직접 선택해야 했던 물리 설정을 미리 채워 넣습니다.
- 감지는 모든 모델에서 동일한 규칙을 따르므로 결과가 일관되며, 물론 모든 항목을 수동으로 조정할 수도 있습니다.

### 손에 맞는 포즈 작업

- 팔다리 드래그에 스무딩이 적용되어, 마우스를 빠르게 튕겨도 튀지 않고 부드럽게 자리를 잡습니다.
- 팔과 다리가 자연스러운 가동 범위를 넘어 꺾이지 않습니다. 제한이 포즈 솔버 자체에 들어갔고, 선택적으로 켤 수 있는 팔 원뿔 제한도 추가되었습니다.
- 다리가 발뿐 아니라 발끝까지 사용해 도달하므로, 뻗은 끝에서 발이 더 자연스럽게 닿습니다.
- 이동·회전 디스크의 위치가 개선되었습니다.

### 더 나은 그랩

- 손이 더 안정적으로 붙잡습니다. 가까운 두 대상 사이에서 깜빡이며 바뀌지 않고, 손이 확실히 멀어질 때까지 그립이 유지됩니다.
- 손가락이 여러 형태를 한 번에 감쌀 수 있고, 대상이 움직이면 그립도 함께 따라갑니다.
- 이제 자기 자신뿐 아니라 무대 소품과 다른 캐릭터의 몸도 잡을 수 있습니다.

### 머티리얼과 룩

- 머티리얼 시스템을 정리하면서 잘못 분류되던 여러 머티리얼을 수정했습니다. 유리, 디더, 머리카락, 바닥, 패스 트레이싱 변형이 모두 의도한 대로 렌더링됩니다.
- 머티리얼 에셋이 없을 때 조용히 잘못된 룩으로 대체되지 않고 명확히 보고됩니다.
- 젖은 표현이 복원되고 한층 개선되었습니다. 새로운 물 셰이더, 바닥 빗물 수정, 더 자연스러운 빗방울 분포가 포함됩니다.
- 새로운 광선 빔 셰이더가 추가되었습니다.

## 그 밖의 새로운 소식

### DanceXR Native — 공개 프리뷰

- NVIDIA RTX 하드웨어에서 완전한 패스 트레이싱으로 캐릭터를 렌더링하는 독립형 Windows 애플리케이션입니다. 실시간 근사가 아닌 실제 반사광, 부드러운 그림자, 진짜 반사를 제공합니다.
- XPS 모델과 VMD 모션을 드래그 앤 드롭으로 불러오며, 오디오 재생, 카메라 모션, 머리카락 및 소프트바디 물리, 발 접지 보정, 절차적 대기 모션, 그리고 볼류메트릭 포그와 광선을 갖춘 절차적 방을 지원합니다.
- 데스크톱 전용(VR 미지원)이며, 레이 트레이싱을 지원하는 GPU가 탑재된 Windows가 필요합니다. 무료 프리뷰는 한 번에 한 캐릭터를 렌더링합니다. 초기 공개 프리뷰이므로 다듬어지지 않은 부분이 있을 수 있으니 피드백을 보내주세요.

## 개선 사항

### 버그 수정

- 포즈 작업 중 골반 오프셋이 밀리던 문제를 수정했습니다.
- 포즈 시각화 크기가 잘못 표시되던 문제를 수정했습니다.

## 이번 업데이트 한눈에 보기

- 모델 로드 시 머리카락·치마·소프트바디 물리 자동 설정
- 부드러운 팔다리 드래그와 자연스러운 관절 제한
- 발끝까지 사용해 도달하는 다리와 위치가 개선된 이동·회전 디스크
- 확실히 붙잡고, 여러 형태에 걸치며, 소품과 다른 캐릭터에게도 닿는 그랩
- 복원된 젖은 표현, 새로운 물·빔 셰이더, 머티리얼 수정
- 패스 트레이싱 뷰어 DanceXR Native 공개 프리뷰 시작

이번 릴리스가 다루는 것은 원래 신경 쓰지 않아도 되는 부분들입니다. 스스로 잡히는 물리 설정, 놓은 자리에 그대로 남는 포즈, 그리고 제작 의도대로 보이는 머티리얼입니다.
